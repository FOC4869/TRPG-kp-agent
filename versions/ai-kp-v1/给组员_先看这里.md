# 给组员：解压后先看这里

这是当前“一名玩家、一张角色卡、一个书房场景”的 AI KP 开发版。
已接入 DeepSeek，包含 Agent、规则检索、骰子、角色状态、存档和命令行界面。
React 页面和 FastAPI 路由还需要继续接。当前实现以 README.md 为准，DESIGN.md 保留了较大的早期设想。

## 1. 先跑离线版

建议 Python 3.12。从仓库下载后，请进入 `versions/ai-kp-v1/` 文件夹。

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-agent.txt
.venv/bin/python -m kp_agent --mode demo
```

Windows PowerShell（安装了 Python 3.12）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-agent.txt
.\.venv\Scripts\python.exe -m kp_agent --mode demo
```

离线版用于跑流程，不是大模型。骰子仍随机。

## 2. 再开 DeepSeek 版

把 `.env.example` 复制为同目录的 `.env`，在自己的电脑填 `DEEPSEEK_API_KEY`。
模型名、其他选项按示例保留即可。密钥不用发到群里，也不要提交 GitHub。

macOS 配好环境后双击 `run_deepseek.command`，Windows 双击 `run_deepseek.bat`；也可运行：

```bash
# macOS / Linux
.venv/bin/python -m kp_agent --mode deepseek --db saves/deepseek.sqlite3
```

```powershell
# Windows
.\.venv\Scripts\python.exe -m kp_agent --mode deepseek --db saves/deepseek.sqlite3
```

首次运行会自动创建自己的存档和规则索引。压缩包没有任何人的 API Key、原玩家存档或虚拟环境。

## 3. 可以试什么

看看房间 → 问问管家 → 调查书桌 → 若失败可花十分钟仔细检查书桌 → 调查壁炉 → 离开 → 问“什么信息没有找到”。

`/status` 看角色和进度，`/history` 看对话，`/retry` 恢复失败消息，`/restart` 重开，`/review` 结束后复盘，`/quit` 退出。

书桌补查是这个短场景写好的另一条路线，不是所有 COC 检定都能花时间自动成功。
