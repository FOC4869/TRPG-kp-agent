# COC 7e 核心规则（节选）

## 成功等级判定

进行技能或属性检定时，掷百分骰（d100），出目越低越好：

- 大成功：出目 01
- 极难成功：出目 ≤ 技能值/5（向下取整）
- 困难成功：出目 ≤ 技能值/2（向下取整）
- 常规成功：出目 ≤ 技能值
- 失败：出目 > 技能值
- 大失败：这次检定的成功目标上限 < 50 时出目 96~100；成功目标上限 ≥ 50 时出目 100（按所用核心规则书 PDF 第 75 页；若改用房规须标注）

## 派生属性公式

- 生命值上限 HP =（体质 CON + 体型 SIZ）/ 10，向下取整
- 魔法值上限 MP = 意志 POW / 5，向下取整
- 起始理智 SAN = 意志 POW
- 理智上限 = 99 - 克苏鲁神话
- 移动力 MOV 基础 8：力量与敏捷均大于体型则 9，均小于则 7
- 重伤阈值 = HP 上限的一半

## 伤害加值与体格

伤害加值（DB）与体格（Build）由 力量+体型 决定：

- 2~64：DB -2，体格 -2
- 65~84：DB -1，体格 -1
- 85~124：DB 0，体格 0
- 125~164：DB +1D4，体格 1
- 165~204：DB +1D6，体格 2
- 205~284：DB +2D6，体格 3

## 理智与疯狂

- 单次理智损失 ≥ 5 点：需智力检定，成功进入临时性疯狂；失败压抑记忆，不会因此次损失进入临时性疯狂
- 游戏中的一天累计理智损失 ≥ 日初理智的 1/5：进入不定性疯狂。实现时保存固定 day_start_san 与 day_san_loss，不按每次扣损后的当前 SAN 重新计算；游戏日边界由场景休息规则确定
- 理智归零：陷入永久疯狂，失去角色控制

## 成长检定

获得成长标记后在幕间检定：掷 d100，出目 > 当前技能值，或者出目 > 95，则技能 +1D10；按核心规则书 PDF 第 79 页，该方式可超过 100。首版单场景不自动执行成长。
