## 当前范围

- 可实际游玩：理查德，原创“雨夜来信”，旧书房 → 旧车站 → 地下档案室，允许回访。
- 页面资料：共 11 位人物、2 个故事；《岭下暗影》列有 11 个地点，但没有接入当前可玩的流程。
- AI 直接担任 KP：理解输入、调用受控工具、叙述结果。真人用于调试或接管，没有每轮真人审批。
- 只有一套 Agent。工具是当前 Python 函数和数据契约，没有运行外部 MCP 服务。
- 网页默认规则检索为本地关键词检索；保留可选 embedding 支持不等于本轮做过向量检索质量实验。
