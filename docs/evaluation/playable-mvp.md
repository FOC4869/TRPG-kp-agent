## 真实模型验证

使用 `deepseek-flash`，Responses API，关闭思考，规划结构化输出，叙述流式输出，不自动重试。用户给定本轮上限为 60 个玩家回合／120 次模型请求。

| 场景 | 玩家回合／请求 |
|---|---|
| 完整同行路线 | 21 回合／42 请求 |
| 完整失踪营救路线 | 13 回合／26 请求 |
| 浏览器真实操作、检定和断线恢复 | 6 回合／12 请求 |
| 最新运行器撤离确认回归 | 2 回合／3 请求，确认提示不调用叙述模型 |
| 六个语义规划样例、一个连接规划探针 | 7 请求 |
| 两轮针对性叙述回归 | 4 请求 |
| **合计** | **42 个完整回合，另有探针；94 请求** |

两条完整路线共 34 回合，行动理解均映射预期事件，均以 `completed` 结束。基线耗时中位数 2719ms／回合，范围 1733–4508ms；68 请求累计输入 123683 token、输出 3854 token。这些是当次实测值，不是延迟承诺。未进行真人 20–30 分钟时长测定。

检定基线包含侦查 20／25 成功、EDU 32／87 成功、SAN 4／65 成功、SAN 81／65 失败并损失 1D6＝6；失踪线首次目击 SAN 4／65 成功。浏览器额外观察到侦查 39／25 失败，刷新后保持同一出目和单张检定卡。其他随机成败与 HP／SAN 归零由可控制出目的离线测试覆盖。

语义样例覆盖“他？”的澄清、假设砸墙只问后果、明确否定现在出发并约次日、未支持的传送术、询问乔什未知蛇人计划、家族话题同义表达。浏览器向乔什询问未揭示秘密时，回应没有提供地下真相。样例通过不表示所有自然语言均可正确理解。

### 发现与修正

初版提示 `mvp-1` 的路线虽在规则状态上完成，复核正文发现：已通过威胁后仍沿用“蛇人挡路”的初始描述；撤离时错误暗示同行的乔什会被留下；把线索信息说成携带实物。

当前 `mvp-2` 按已提交状态生成场景描述，明确通路、牢笼和乔什状态，并要求当前事实优先于旧对话。地下撤离与固定 3 HP 强行通过采用确定性确认提示，未获确认不执行。新增离线回归及真实模型回归验证：确认提示没有提前结案；随后明确确认才以 `completed` 返回地面；正文不再重复阻断已通过通路。历史基线记录保留原样，不把修正后的结果倒填到旧报告。

模型仍可能生成未登记的气氛细节或不准确措辞。它不能修改实际出目、HP／SAN、物品、线索、事件前提或结案；重要确认由运行器输出。当前验证不能证明完全杜绝叙述幻觉。

本地原始证据位于 Git 忽略的 `backend/output/web-mvp-evaluation/`：`report.json`、`semantics.json`、初版与最终 `narration-regression*.json`、`confirmation-regression.json`。存档另含每次请求的模型、提示版本／哈希、输入哈希、用量、耗时及失败阶段。可复核摘要见 [JSON](playable-mvp-summary.json)。

完整路线复现：从 `backend/` 显式运行 `uv run --locked python scripts/evaluate_web_mvp.py --live`，会调用付费模型。脚本稳定 ID 及检查点可继续已有评估，最多 90 请求；已有完整报告不会重复运行。若要复核最新提示的完整路线，须在新的明确授权和预算下安排，不删除报告绕开本轮限额。

## 桌面与浏览器验收

Playwright 真实浏览器覆盖首页→模组→调查员→创建，中文自由输入、建议填入、场景／NPC 图层、实际资源和线索更新、检定卡、刷新、断网后同请求恢复，以及后端重启后读取。网络异常独立显示，没有切回假回复。结案保存后弹窗，Escape／关闭可回看，重新打开和键盘返回首页通过。

| 视口 | 验证 |
|---|---|
| 1440×900 | 长历史页面宽高保持 1440×900；正文和约 7768px 的抽屉内容内部滚动 |
| 1280×720 | 页面宽高保持 1280×720；正文容器约 172px、历史内容约 5381px；输入／结案操作可见，无坏图 |
| 390×844 | 无横向溢出；结案弹窗和返回按钮在视口内，键盘可达；历史检定不重播 |
| 系统减少动态效果 | 直接展示结果；已完成历史没有掷骰动画 |

发现并修复检定卡辅助朗读文本因绝对定位越出滚动容器、导致外层页面被长历史撑高的问题；修复后复测两个桌面视口和历史抽屉通过。SSE 读取不等待检定动画，多个结果和后续正文顺序播放。浏览器截图在忽略的 `output/playwright/`，包括 `game-1280x720.png`、`completed-1280x720.png`、`completed-1440x900.png`、`ending-390x844.png`。

## 复核与后续边界

产品视角：十人、两条乔什时间线、六场景、可选调查和三类结案已覆盖；普通失败不会阻断主线，撤离始终可选。工程视角：随机结果先保存、效果一次提交、叙述最后保存；未决回合必须恢复，损坏文件保留现场。安全视角：仅公开投影及已揭示素材；无原始存档／目录静态挂载；服务器错误不回传供应商原文。QA 视角：先离线与接口验证，再真实模型和桌面试玩，发现项已回归。

仅支持本地单进程／单 worker，没有账号或多人授权系统，游戏地址用于恢复。Windows 文件锁实现未在 Windows 实机验证。复杂战斗、重伤、疯狂、法术、追逐、真人接管、存档管理和多进程事务属于后续工作。当前配置可游玩，不声明原完整模组全面可执行。
