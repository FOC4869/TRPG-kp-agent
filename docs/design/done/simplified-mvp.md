# CoC AI Keeper：可游玩单人 MVP

2026-10-24，用户批准计划已实现；工程契约见 [实施记录](playable-mvp-implementation.md)，验证见 [评估记录](../../evaluation/playable-mvp.md)。

## 范围

首页、模组库／详情、十位真实调查员选择、游戏页及游戏内结案弹窗。自由输入；真实DeepSeek负责理解、受约束事件选择、NPC扮演和流式叙述。服务端执行检定与状态，模型不能指定出目或自由修改资源。正常每轮一次结构化规划、一次结果叙述，无额外建议或总结调用。

首版仅普通D100成败、HP/SAN、关键物品、线索与简化危险。HP/SAN归零失败。不实现完整战斗、重伤、疯狂、法术、追逐、多人、真人接管和存档管理。MP/幸运仅展示模板值。

## 路线与规则

| 场景 | 已执行事件 |
|---|---|
| 文斯考特宅 | 交谈隧道／家族；现在探索乔什同行，次日返回乔什失踪 |
| 地窖 | 检查入口；手电／绳索／撬棍领取一次；带手电进入地下 |
| 旧隧道 | 显眼遗骸直接获得、衣物免检定；侦查一次获得可选新近痕迹，失败不锁死 |
| 入口厅 | 雕刻；DEX穿过碎石失败1D3HP但仍通过；有绳索可免检定；旁路历史厅 |
| 历史厅（可选） | EDU一次解读，成功获得解释并SAN0/1D3一次 |
| 牢笼区／终场 | 首见蛇形生物SAN0/1D6一次；潜行／话术／斗殴各一次，失败1D6HP、警戒；明确固定3HP强行通过可作补救；撬棍免检定开笼或STR一次，失败可回取工具 |

同行线调查铁笼证据后可返回；失踪线开笼帮助乔什后，他才跟随。NPC不额外掷骰或加成。原包保持只读，独立 `backend/data/runtime/darkness-solo-mvp-v1.json` 标注改编和引用，不宣称原完整模组全面可执行。目录通过runtimeProfile绑定此次验证配置。

完成：最终事件解决、调查员与乔什安全返回。撤离：玩家明确结束但未完成目标或留下乔什。失败：HP或SAN归零。普通回头不结案；地下结束先询问确认；最终总结区分救出／同行／留下乔什。

## 状态与Agent

每局 `backend/saves/<game_id>/game.json` 保存初始人物快照、当前资源、NPC位置／阶段／话题、物品、线索、场景／事件进度、完整历史、请求与出目和执行阶段。模板不回写。带校验和的原子替换和有效备份；不兼容或损坏明确报错、保留现场。单进程／单worker、同局串行，浏览器断线不取消任务。

LangGraph：读取／恢复 → 当前场景和合法事件上下文 → 结构化理解 → 条件校验／执行工具 → 保存出目 → 一次提交效果 → 流式正文 → 保存回复。只供近期历史与结构化状态，不引入向量库或摘要调用。叙述只见已提交事实和公开知识；非执行问答不改变世界。

每轮正常最多两次模型调用，单次45秒、整轮120秒，不自动重试。明确恢复时复用请求ID，已保存骰子和已提交效果不重做，叙述可重生。指标只记模型／提示版本、输入hash、耗时、用量及失败阶段，不记密钥。

## 前端与SSE

创建／读取／行动／素材接口见 [interfaces](../../interfaces.md)。路由 `#/game?game=<id>` 刷新恢复。检定卡在对话内部滚动，约0.8秒动画后显示服务器结果；多个检定与正文依次展示，读取网络持续进行。减少动态效果直接显示，历史不重播，损失骰在明细展示。最终回复已保存才弹结案。

侧栏资源条使用固定底槽与动态填充：HP／MP 按当前值除以上限，SAN／幸运按百分制显示；读取与 SSE 状态更新均同步数值和长度。填充限制在 0–100%，缺值或无有效上限时留空；数值文本保留，装饰条不重复进入辅助阅读。

场景左下角的“本轮变化”显示实际资源增减、物品及线索变化，默认8秒消失，悬停／聚焦时保留，支持关闭与内部滚动。比较公开快照而非叙述或骰子原始损失；首次读取、刷新、相同版本与已提交回合恢复不重放提示。见[展示约定与验证](game-state-feedback.md)。

正常前进不会静默切mock，网络错误独立提示；先读状态再恢复原请求，未确认原结果前禁止编辑换新请求。

## 验证与剩余范围

离线测试覆盖十人、隔离、三结局、两线、可选检定失败、双检定、重复／并发／断线、出目与提交断点、重启、损坏、版本和素材边界。前端类型／构建／SSE拆块测试及桌面试玩见评估记录。真实模型调用已获本任务授权，总上限60回合／120请求。

20–30分钟为玩法目标，脚本快速通关不代表实际游玩时长。自然语言具有模型误判／措辞偏差风险，实际数值与结局受配置约束。Windows锁实现保留但此轮仅在macOS验证。复杂CoC规则、账号、多进程存储与存档管理另列后续工作。
