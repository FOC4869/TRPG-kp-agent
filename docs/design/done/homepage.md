# 桌面首页

状态：已完成。2026-10-22，分支 design/frontend-ui。依据本次用户确认的首页概念图与五页用户旅程。

## 目标与范围

实现可独立打开的桌面首页：旧宅、雨夜和烛光背景，左侧 CoC AI Keeper 标题与开始调查按钮，顶部导航，底部简短玩法说明。继续调查使用原生 disabled，明确标注暂未开放；本轮不实现存档。

主要面向电脑，验收 1280×720、1440×900、1920×1080 和宽屏；短窗口允许纵向滚动，小屏保持基本可用。所有文字与交互使用 HTML，生图只用于不含文字的背景。中文正文使用系统宋体回退，不依赖远程字体。

开始调查和模组库打开同一模组预览对话框，仅展示原创演示故事的公开简介；角色选择与游戏 HTTP 尚未接入，明确标注尚未开放，不创建游戏或伪造进度。设置对话框提供减少动态效果开关及按需后端健康检查。弹窗支持 Escape、焦点约束和关闭后焦点恢复。

## 文件与切片

1. frontend/public/images/manor-home.webp 与素材说明：生成原创无文字场景，压缩为 WebP；检查清晰度、加载体积和背景裁切。
2. frontend/src/App.tsx、styles/base.css、styles/home.css、index.css、index.html：实现首页、可访问导航和原生 dialog。验证 npm ci、lint、typecheck、build。
3. README、architecture、development、memory-bank 与本文件：同步实际页面和限制。用浏览器核对桌面视口裁切、短屏滚动、弹窗与键盘交互；布局与焦点需在真实页面确认。

## 边界与验收

- 不修改后端接口、数据库、模型、规则或剧情；不把后端角色卡、隐藏信息或存档打包到前端。
- 无新运行时依赖，不调用付费 LLM；素材通过内置 imagegen 生成。
- 首页可在无后端时浏览；健康检查只在设置打开时执行，错误可重试。
- 主按钮和导航可操作，继续调查不能激活；无自动保存或存档读取。
- 设计、代码、DX 与 QA 在本会话顺序检查；不使用子代理。
- 回退方式为恢复本次前端与文档变更，无数据库迁移。

## 验证结果

- npm ci、lint、typecheck、build 全部通过；无新增依赖。
- 真实浏览器布局检查：1280×720、1440×900、1920×1080、2560×1080 没有横向溢出，主按钮与底部信息完整显示；1280×600 纵向滚动保留全部内容；390×844 可用。
- 开始调查/模组库打开预览，继续调查为原生 disabled；Escape 关闭后焦点回到触发按钮。原生 modal 约束背景交互，Tab 可在弹窗控件间导航。
- 减少动态效果勾选后浮尘 animation-name 为 none；设置断开后端时显示失败，启动健康服务后重试恢复连接。
