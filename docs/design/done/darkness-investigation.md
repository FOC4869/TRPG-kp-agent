# 《岭下暗影》调查扩充

目标：扩充可调查的内容，让线索影响可用方法、风险和结案事实。沿用通用工具运行器，不将模组逻辑写回 Python。

## 范围和改编

新增 v3 / 3.0.0，原正文、素材以及 v1/v2 配置不变。十一场景：宅邸、地窖、图书馆、旧隧道、河道封墙、入口厅、历史厅、音乐室、巢窟、陷坑走廊、牢笼区。城内查档不自动推进至次日；只有明确选择次日返回才触发乔什失踪。

主线为宅邸 → 地窖 → 旧隧道 → 入口厅 → 陷坑走廊 → 牢笼区；图书馆、河墙、壁画、音乐室和巢窟均可选。最终仍为调查完成／主动撤离／HP或SAN归零失败。

依据原文 `winscott-family`、`peck-letter-discovery`、`entering-underground`、`history-hall`、`music-room`、`degenerate-nest`、`pit`、`captivity`、`friend-in-distress`。图书馆合并两处查档来源并免除会员费；地下地图压缩连接；河墙可修出逃生口、音乐掩护和明确代价的带人离开属于单人改编。音乐不控制蛇人，不让旧信提供原文没有的精确地图。复杂战斗、法术、毒物计时、传送门和新美术不在范围。

## 决策及可观察结果

- 立即同行／次日返回：保持两条互斥时间线，失踪线增加安抚与带人离开。
- 先研究、查河墙或直接深入：选支线获得证据／备用出口，代价为额外行动或检定风险，不强制跑完支线。
- 安静调查音乐机关／主动演奏：后者损失固定1SAN（检查装置时预先说明）、引动外围巡逻，换取掩护机会；最终蛇人初见SAN仍执行。
- 看清陷坑再绕行／直接跨越：前者免检定，后者可能HP损失。
- 借线索安抚／技能尝试／强行带走乔什：线索免检定，技能失败使他更惊慌但不锁死；明示确认1HP代价后仍可带离。
- 原路撤离／已准备的河岸出口：明确选择返回位置，河岸出口未准备时不能使用。所有地下结束均需现有撤离确认；普通返回不是结案。
- 救人优先／继续收集证据：结案只陈述实际所得、同行或营救事实，不因缺支线资料拒绝完成。
