# 调查员选择页

2026-10-23，design/frontend-ui；用户确认十人照片墙与右侧档案概念图，要求使用假资源和假数据，预留 API 接入。

## 范围与交互

- 桌面左侧 2×5 人物卡片、右侧档案面板；与模组库共用导航、背景、金色细线和页脚。
- 模组库选择调查员进入 #/investigators?module=<id>，页面通过适配层获取模组标题与可选人物。缺少/无效模组显示返回模组库入口，不凭空选取模组。
- 首次无选中人物；点击后请求详情，显示姓名、职业、年龄、头像及人物概览/属性技能/人物背景/初始物品四标签。
- 概览含摘要、HP/SAN/MP/幸运与主要技能。SAN 不补上限，未知字段显示未提供；空列表、加载、读取失败和重试可见。
- 确认调查员显示所选案件与人物的准备弹窗；游戏未实现，不创建游戏/存档，不请求模型。
- 照片与十条人物记录为独立前端示例，不能从 backend/data/characters 复制 YAML、背景或头像。示例仅验证 UI，不声称是原卡忠实转录。

## 接入边界

types/investigators.ts 定义客户端公开摘要/详情；api/investigators.ts 提供 listInvestigators/getInvestigator，接收 moduleId 与 AbortSignal。当前经本地 mock 适配，未来替换为经确认的 HTTP 契约；不编造已存在的后端 URL。
摘要仅需 ID、展示名、职业、年龄和授权头像 URL；详情为专门的展示投影，不传 source、source_issues、附件路径、模板全文或私密资料。sprite 仅为假头像图集的可选展示信息，真实接口可返回普通图片 URL。
切换人物时取消旧请求，响应只有在未取消时才提交；详情与选择 ID 一致且加载完成后才允许确认。模板和游戏实例仍由未来后端管理。

## 后续调整：档案内部滚动

用户反馈长标签会撑高整个页面。档案改为视口自适应的固定高度，头像、标签栏与底部确认区域保留位置；只有当前标签内容 overflow-y: auto，支持键盘滚动与独立滚动条，并阻止滚动到边界后继续带动外层。内容区预留滚动条空间，避免切换时宽度跳变。
验证四标签的档案高度和确认按钮位置一致；键盘 End 可滚到内容底部，页面 scrollY 保持 0。1280×720、1440×900、1920×1080 桌面整页高度保持视口高度，390px 窄屏无横向溢出且确认按钮保留在档案内部。lint/typecheck/build 和 diff 检查通过；无依赖或后端变更。
