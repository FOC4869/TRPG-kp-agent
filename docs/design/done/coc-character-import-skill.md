# 自包含角色卡导入技能

用户确认：在 skills/coc-character-card-import/ 维护通用 CoC 图片导入技能，并复制安装到个人技能目录。只依赖技能本身和用户输入，不依赖项目角色实现、原始十位角色或历史对话。

输出固定为 <root>/<id>/{character.yaml,background.md,assets/portrait.png}，无 manifest，无整卡留存。默认不覆盖；缺输出位置先询问；原卡疑点记录而不猜补。技能包含完整字段说明及虚构示例、裁切/校验脚本、UI 元数据，支持 npx skills add 的仓库发现。

实施：初始化技能；完成说明、脚本与样例；隔离测试并进行无项目上下文试用；验证后复制到个人目录并比较内容。项目 README 增加安装说明。不修改游戏及已有角色，不自动提交或推送。

验证：quick_validate；裁切边界和不覆盖；YAML重复键/ID、相对引用、锚点、攻击、装备、图片；有效但含疑点、无头像；隔离导入与 CLI 发现；安装副本一致。命中 DX、数据完整性和可移植性 review，本会话顺序检查。
