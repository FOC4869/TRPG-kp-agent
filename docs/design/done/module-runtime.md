## 边界

保留当前 HTTP／SSE、状态保存与检定展示，不扩展复杂 CoC。模组定义初始状态、场景连接、NPC 知识与可见性、实体、线索、物品、挑战及结案条件。Agent 调用 move／observe／talk／take／interact／finish 等通用工具；普通观察与在场 NPC 交谈无需逐句事件配置。挑战定义目标、允许技能／物品辅助、成功与失败后果，Agent 可解释临场策略并在允许能力内选用技能；不能直接发放线索、修改 NPC 或指定出目。未支持的能力明确说明。

模组注册按 moduleId 与 runtimeProfile 解析，不扫描或执行任意路径。正文上下文只含已提交公开事实及 NPC 可说的知识；条件、未来线索与完整原文不传前端，也不直接传给正文模型。
