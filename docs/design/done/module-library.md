## 目标与边界

- 桌面每页最多 3 张纵向卷宗卡片，左右按钮分页；首尾按钮禁用，末页不补空卡。
- 选中卡片显示金色边框、标记与右侧公开详情。翻页默认选中本页首项。
- 主模组为《岭下暗影》，使用用户提供的引言：1920 年代普罗维登斯，乔什·文斯考特发现地窖隧道并邀请熟人调查。仅公开开局信息，不包含守秘人背景或真相。
- 临时提供 7 条前端示例记录：1 个已知模组、6 个清楚标注待收录的占位记录，用于 3/3/1 分页及选择交互。它们不是后台已有的正式模组。接真实接口后仅渲染接口返回记录。
- api/modules.ts 提供带取消信号的分页读取适配点；本轮读取本地 fixture，不发明或调用尚不存在的 HTTP 路由。
- 首页开始调查与导航进入 #/modules，支持直接打开、刷新和浏览器前进后退；设置仍为共享弹窗，存档保持禁用。
- 选择调查员按钮仅对主模组可操作，打开尚未开放提示；不实现调查员页面或启动游戏。
- 原创无文字封面只表现地窖、石阶、提灯与未知通道；不使用完整 UI 生图代替可操作页面。
