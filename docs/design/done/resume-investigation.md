# 首页继续最近调查

用户已确认：先支持最近一局，不添加存档列表。复用现有 GET 游戏状态和 `#/game?game=<id>`，不增加游戏创建、行动或模型调用。

## 行为与边界

- 创建成功、直接打开有效游戏地址读取时，仅将可恢复的 game_id 记入浏览器 localStorage；后续快照仅负责清理已结案的同一编号。完整状态仍只在后端 JSON；不保存角色、对话或密钥。
- 首页读取本地编号并调用 GET 校验，未结束则启用“继续调查”，显示模组和调查员；点击打开原游戏。存在未完成回合时，由游戏页显示现有“恢复本轮”，不自动重发行动。
- 无编号、已完成结案或明确404时禁用按钮。HP/SAN已终局但最终回复仍待恢复的回合继续保留入口。
- 网络、损坏或版本错误保留编号，明确提示并允许重新检查，不把临时故障当成删除存档。禁用本地存储时正常游戏与原URL恢复仍可用。
- 只清除与当前结束／失效游戏相同的编号，避免其他标签页结束旧局时误清除新局。首页重新进入、窗口聚焦及其他标签页更改编号时重新校验，并取消旧请求。
- 此前已有的游戏须先用原地址打开一次才能记住；不扫描服务器目录，不跨浏览器发现存档。

剩余限制：同源同浏览器只记一局，清理浏览器数据后须用原地址打开；本地存储不可用不会阻断游戏，但不能记住首页入口。没有多局管理、跨设备同步或账号权限。
