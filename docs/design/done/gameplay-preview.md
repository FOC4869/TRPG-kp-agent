# 游戏主界面：开场预览

2026-10-23，用户确认场景＋独立 NPC 立绘的概念图后要求实现。沿用已确认的五页旅程，本轮实现游戏主界面；后端尚只有健康 HTTP。

## 范围与边界

- 新分支 feat/gameplay-preview，从干净 design/frontend-ui 建立，当前 checkout 开发，无并行任务或结构迁移。
- 调查员确认页进入 #/game?module=<id>&investigator=<id>。上下文缺失/无效时返回选择入口，不默选人物。刷新重置本地预览，不表示存档。
- 桌面顶部窄栏、左侧调查员资源与工具入口、右侧背景/NPC、固定高度且内部滚动的叙事流、底部自由行动输入与可选建议。移动端保留基本可用性。
- 原生 dialog 作为右侧抽屉，提供人物、物品、已发现线索、完整记录、设置。Escape/关闭恢复焦点；不提供存档按钮。
- 自由输入调用异步 mock 适配，不调用真实模型，不声称完成自然语言游戏裁定。开场回复范围仅乔什会面；未知行动清楚提示预览范围。固定检定示例从设置中手动查看，不对自由输入自动掷骰，不修改资源。
- 本轮用户明确要求使用已审阅素材实现开场。仅将住宅背景和乔什立绘作为开场预览的独立允许清单拷贝到 frontend/public/images/game-preview；不读取/打包模组 YAML、正文、角色卡、秘密场景或整包资源。此预览特例不改变原素材 keeper_only，也不代替未来按 game_id 授权的素材 HTTP。无新增 Vite 目录暴露。
- 人物使用既有独立前端假资料；UI 消息为开场公开内容的简短演示改写，不加载后端正文。

## 实施切片

1. types/game.ts、data/game-preview.ts、api/game.ts：公开展示 DTO、异步可取消初始化/行动入口；注入未来服务器授权状态和消息，不在组件实现 CoC 规则。验证上下文、取消、独立副本、建议和未知行动、固定检定示例。
2. GamePage/GameDrawer、game.css：可玩预览，防重复提交、等待/失败/同请求重试；保留草稿，组件卸载取消请求。确认路由保留 module/investigator。图像失败有占位，立绘失败不阻塞输入。
3. 文档与 Memory 同步，记录开场素材来源/授权范围，验证固定高度、滚动、抽屉、输入法、刷新/返回、无效上下文。

## 验证与评审

顺序进行 Product/Eng/Design/Code/DX/QA 自查，不分配子代理。npm ci/lint/typecheck/build、适配 smoke 和 git diff --check。现有 development 文档要求桌面/窄屏视觉验收，因此浏览器检查 1280×720、1440×900、1920×1080、390px 及核心交互，保存截图。无后端改动，不重复后端测试或真实模型评估。回退本轮前端/文档可恢复旧确认预览；无数据迁移。

## 结果

- 三个切片已完成。顺序复核产品范围、展示/运行时边界、键盘/布局、取消与请求去重、文档入口；无子代理、无新依赖、无后端变更。
- npm ci、lint（零警告）、typecheck、build、git diff --check 通过；node scripts/check-game-preview.mjs 覆盖上下文、副本隔离、初始化/行动取消、重复 requestId、空/超长输入、公开事实与固定检定，全部通过。
- 浏览器：调查员确认进入游戏并保留人物；空线索、行动发送/等待/防重复、未知行动提示、Shift+Enter、交谈后线索及重复交谈去重、人物/物品/线索/记录/设置抽屉、Escape 与焦点返回、手动检定卡、历史滚动/最新按钮、刷新回开场、缺失上下文/无效模组均核对。中文输入法采用 composition/229 双重保护，未模拟真实输入法候选流程。
- 1280×720、1440×900、1920×1080 下页面高度等于视口，长记录只在叙事区滚动；390×844 下外层自然滚动，无横向溢出。两张场景图片均实际加载，浏览器 error 日志为空。
- 两张静态预览图片哈希与来源一致；仅明确的开场允许清单进入 public，未打包 YAML、正文、角色卡或其他后台素材。
