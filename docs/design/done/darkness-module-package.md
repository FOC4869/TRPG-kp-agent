# 岭下暗影模组文件包

## 来源与范围

需求来自本次用户会话：采用 Markdown 正文、YAML 结构化配置和统一 assets/；将提供的完整中文正文和七张原书素材保存为 darkness-beneath-the-hill 模组，使用独立分支与工作树。

交付 backend/data/modules/darkness-beneath-the-hill/，包含完整正文、人物、地点、线索、物件、事件、结局、可选主持建议、疑点和素材索引。图片保持原始字节；通过稳定 ID、关联实体、标签与揭示条件索引，不强制按素材类型建立子目录。

## 边界

这是内容包草案，不是已接入 KeeperService 的可运行模组。YAML 为声明资料，不执行表达式、不调用模型、不自动应用规则。既有 campaign.json、CLI、HTTP、SQLite 与 frontend 保持现状。规则未明确和图像连接未核准的地方保留 issue；法术只列外部规则依赖。所有素材默认仅服务端内部访问，player 条件是未来接入契约，当前不存在公开素材接口。

## 实施顺序与验收

1. 保存完整正文并增加稳定章节锚点；核对原文可完整还原（仅换行标准化和插入标题锚点）。
2. 保存七张素材与索引，记录 SHA-256、来源附件、关联和访问条件；检查文件、校验和及引用。
3. 提取主要实体与事件。原文、可选建议、技术约定、未决解释分开记录；事件保留成功、失败与延迟说明，不声称运行时已支持。
4. 自审内容/架构/权限/DX；解析所有 YAML、核查 ID/出处/文件路径/素材哈希；运行后端离线单元测试。

仅涉及后端静态内容和说明文档，不新增依赖或前端代码，不触发浏览器 QA。回滚为移除本次新增文件及文档段落。

## 验证结果（2026-10-22）

- 10份YAML使用本机已有PyYAML的SafeLoader解析，额外拒绝重复键；未新增项目依赖。
- 去除新增锚点后story.md与附件标准化换行文本完全一致；保留译注及排版残留。38个锚点唯一且所有source/content_ref可定位。
- 57个实体ID、素材关联、地点连接、issue与可选项引用均核对通过。
- 7张PNG逐字节复制，魔数和SHA-256一致；另有2份文字展示材料引用正文，所有素材默认keeper_only，可选主持建议全部默认关闭。
- 45项事件提取；音乐室看清头颅与接触椅子分别登记，避免把观察和操作混成一个触发。
- backend执行 `uv run --locked python -m unittest discover -s tests -t . -q`：191项通过（7.925秒）；仅有既有openpyxl扩展告警。
- 内容、架构、权限和开发说明自审完成：没有运行时接入、前端秘密打包、HTTP公开路径或付费模型调用。前端未改，不运行前端安装/构建；实际模型主持及规则结算不在本轮范围。
