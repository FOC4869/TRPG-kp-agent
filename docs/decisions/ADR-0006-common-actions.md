# ADR-0006：常见动作、能力快照与持久确认

2026-10-24，已接受，依据用户批准的四步实施方案。

扩展受控工具与声明式目标能力，不让模型返回任意伤害值或JSON patch。全局简化物品规则与模组剧情分离，开局/显式兼容升级保存能力快照；原始角色数据只读。已有schema2存档由匹配templateHash的原模板补充mechanics，GET不写盘、已保存能力不随规则文件变化；新目标剧情单独版本化。
