# ADR-0002：模组内容包与统一附件索引

状态：内容组织方式已采用；运行时集成待单独设计。

背景：现有 campaign.json 是固定三场景的执行输入，无法直接代表用户提供的完整出版模组。用户要求保留正文、可追溯的结构化提取与全部附件。

决定：在 backend/data/modules/<slug>/ 保存 Markdown 正文和 YAML 声明，统一 assets/ 存储任意媒体；assets/index.yaml 通过稳定 ID、相对路径、MIME、实体关联、标签、出处和权限描述素材。目录分类可自选，不具备权限语义。当前不增加通用运行时 schema/loader，也不以这一内容草案替换已有 JSON。

替代方案：仅保存 PDF/图片不便引用执行；全量改写为 YAML 丢失叙事；按 maps/illustrations 等必需目录固定类型限制其他模组的媒体组成。

后果：需要维护原文出处、提取状态和未决问题。加载器、跨游戏权限过滤、规则执行与版本兼容将在后续设计中验证，不能依靠提示词或文件名实施访问控制。生成索引是可重建资料，存档属于独立游戏状态。
