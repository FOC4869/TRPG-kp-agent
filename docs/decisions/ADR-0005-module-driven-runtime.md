# ADR-0005：模组数据与通用工具分离

状态：已接受，2026-10-24。依据：用户确认结构化模组＋开放式 Agent 并要求优化运行器。

上一版固定加载单一配置，初始化、NPC、结案、素材和提示词含专用逻辑。改为显式运行配置注册表与按局内容解析；LangGraph 共享，工具执行与校验共享，剧情定义全部来自已验证的模组数据。

Agent 提出一个主要工具调用（工具、目标、策略／技能／辅助物品），不直接提出任意数值或状态 patch。通用观察与交谈可覆盖非关键临场行动；重要发现与进度、危险成功／失败仍受模组定义约束。原文用于内容制作及后续检索来源，当前不将全部秘密交给正文模型。

采用受限的声明式 schema，拒绝未知操作／悬空引用／路径越界。支持已有能力的模组通过数据接入；新规则能力仍需实现通用工具，不能假装能执行法术或完整战斗。相比全原文主持，增加内容整理工作，换取可测试的状态、知识和结案边界；相比完整事件菜单，允许玩家临场策略映射到挑战能力而非枚举所有说法。

保持 ADR-0004 的单进程 JSON、持久出目、效果一次提交与 SSE。旧指纹通过明确兼容登记转换，不修改历史骰子与回合结果；GET 不写盘，后续保存保留备份。未知版本保留原现场并拒绝恢复。

2026-10-24扩充：内容发布采用“新局current、已有局retained固定指纹”。新增剧情文件，不自动迁移玩家已经作出的选择；v1等价升级仍指向冻结v2。按局先解析历史版本，避免损坏新版阻塞旧局。通用结案支持条件返回地点，原HTTP／SSE和保存结构不变。新机制仍由schema和执行器统一实现，剧情扩充只添加数据。
