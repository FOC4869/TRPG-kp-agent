# CoC Module Builder

交付可审阅、可移植的模组包。规则、情节与线索来自用户提供的来源；视觉发挥需单独记录。安装后的本目录就是完整制作工具，不需要原仓库、聊天记录或其他 skill。

## 输入与读取顺序

接收正文/附件、输出目录；可选规则版本、已有内容包、风格参考和指定阶段。缺正文则先请求来源，不编造完整模组；仅补图时读取已有包即可。默认输出 backend/data/modules/<slug>/，允许用户指定其他目录。已有目录先盘点，不自动覆盖或迁移。

1. 整理内容前读 [module-format.md](references/module-format.md)，按 [templates](assets/templates/) 建立文件；模板是合法空包，不是现成故事。
2. 规划/生图前读 [visual-production.md](references/visual-production.md)。先复用当前已验收风格，再考虑新增。
3. 校验/续做前读 [validation.md](references/validation.md)，运行随附校验器；所有路径相对输出模组根目录，不嵌入个人路径。

## 五个阶段

| 阶段 | 行为与结束产物 |
|---|---|
| 整理内容 | 保留完整正文、来源附件与哈希；插入唯一锚点；提取人物/地点/线索/物件/事件/结局/主持选项/疑点；内容包可离线审阅 |
| 规划素材 | 全量清单：原件复用、专属/共用/默认背景、NPC 基础与必要状态；写视觉规范与完整提示词；不为每个地点强制生图 |
| 制作首批样本 | 默认背景、开场背景、首位主要 NPC 基础立绘；没有 NPC 则明确不适用；用现有文件制作合成预览；提交样本供用户确定风格 |
| 继续生成 | 风格已由用户选定后按只读续做建议生成缺项/修订项；不覆盖已验收文件；表情基于同一角色原图编辑 |
| 校验 | 内容/文件/引用/图像检查＋人工语义检查，报告完成项、剩余项、阻塞问题与产物路径 |

未指定阶段时执行前三阶段后结束，不自动批量补齐。只要求整理/规划/校验时，不额外生图。用户已明确选定参考风格或素材范围时，不重复索要确认。

## 执行约束

- 保留原文，配置附出处；争议留 null 和 issue，不猜规则版本、地图连接或原文未给出的数字。不将章节次序当道路。
- 事件为 descriptive_only；runtime_compatible 始终 false。当前制作不创建游戏、存档、HTTP 路由或加载器。
- 定义、派生制作记录与本局状态分开；原图只读。图片出现的动作、人物、道具数量不是本局事实。
- 原始附件与新图均默认 keeper_only；揭示条件是未来契约，不是授权实现。前端不读取/打包本包。
- 默认写实绘画、克制色彩、清晰暗部；时代与题材取自模组。背景与 NPC 独立生成，不将人物烘焙入背景。
- 优先宿主内置图片生成/编辑工具。Codex 用内置 imagegen；透明立绘必须要求真实透明背景。参考图先查看，变体尽量编辑已有图。不要依赖本机其他 skill 或私有脚本。
- 没有图片工具时仍交付内容包、素材计划与最终提示词，标记 blocked_tool，明确尚未生成；不伪造资源、不画 SVG 代替立绘、不静默调用付费 API。
- 实际生成调用遵循宿主权限。若需新增 API 费用或外部服务，先取得明确授权；不要求用户在聊天中提供密钥。
- 默认每项初次生成后最多两次针对性修正；仍不合格记 failed，保留原因，不无限重试。重试次数存记录，重新执行不重置。
- 生图结果在工具私有位置时，将选定文件保存到模组 assets/ 再引用。生成来源、完整提示词、参考图、风格/内容指纹均随包保存；报告最终路径。

## 检查与交付

按 [validation.md](references/validation.md) 运行只读校验和续做报告。未生成项只存在计划；accepted 项才进素材索引。仅在用户选定风格后继续整批生产。

交付说明：输出目录、内容来源与版本、验收素材与预览、仍未生成项、issue、工具限制和已运行检查。机器检查不证明画风一致、无剧透或可开局，必须区分这三件事。安装与命令见仓库说明；执行不依赖该说明。
