# 网页界面

React + TypeScript + Vite。包含首页、雨夜来信模组、固定理查德角色确认、游戏对话和结案弹窗。
游戏状态从后端读取，支持恢复调查、检定卡、伤害卡、物品与线索面板、危险行动确认。

使用 Node.js 24，在此目录运行：

```sh
npm ci
npm run dev
```

访问 http://127.0.0.1:5175。`/api` 转发到本副本的 http://127.0.0.1:8011，后端需要同时启动。
网页使用后端的 Agent＋RAG，不保存模型密钥或完整剧情文件。回复可展开“规则依据”，查看本轮检索来源和页码；已有对话恢复后保留相同依据。

`npm run build` 生成 `dist/`。首页最近调查仅在当前浏览器记录游戏编号，实际存档由后端保存。
