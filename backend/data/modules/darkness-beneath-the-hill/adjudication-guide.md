这份说明与 rulings.yaml 一起阅读。它是用户授权下选定的本项目规则配置，不是出版物勘误。问题处理完毕不等于规则执行代码、法术或单人适配已经实现。

## 核实与选择

- 标准 CoC7 与当前后端规则一致，作为本项目基线，不启用 Pulp。
- 蛇人采用 HP 11：CON45、SIZ65 的通用派生结果与译注一致；印刷20及原文仍保留。NPC可能有特殊配置，因此明确这是项目采用值，不宣称拿到官方勘误。依据：[Chaosium 派生属性](https://cthulhuwiki.chaosium.com/investigators/step-two-secondary-attributes.html)。
- 妖鬼补齐 SAN 0/1D8，依据：[Roll20 CoC Free Basic Rules 的 Ghast 条目](https://roll20.net/compendium/coc/Monsters:Ghast)。
- 潜行失败选择正文主句的被察觉结果，保留译注争议记录；不额外赋予怪物免费攻击。
- 原文负号与奖励表达式可能有多种解释，项目统一选择“失去1D6+1”，范围2至7；该选择是房规。
- 重试须有不同方法与明确风险；本项目最多一次孤注，并排除战斗、理智和幸运重掷。一般机制依据：[Chaosium 检定规则](https://cthulhuwiki.chaosium.com/rules/game-system.html)。同类怪物SAN按场景与本模组会话上限累计、事件去重是本项目具体策略，不冒充该网页完整原文。
- 传送门借用 MP 不足可由 HP 补足的通用原则；必须保留至少1HP、先验证所有支付条件，以及SAN为1时先移动后处理归零，均是针对本门明确选定的项目边界。依据：[Chaosium 魔法规则](https://cthulhuwiki.chaosium.com/rules/magic.html)。

## 未来执行器必须覆盖的边界

| 场景 | 已选约定 |
|---|---|
| 同一检定请求因网络重试再次到达 | 返回已有骰子与效果，不重掷、不再次扣资源 |
| 同一人重入神殿 | 不重复取得已结算幻象的SAN或神话奖励 |
| 爆炸距离恰好1／2／3码 | 分别使用3D6／2D6／1D6，超过3码为0；成功反应减半向下取整 |
| 绳索失败、孤注又失败 | 只结算一次坠落；若事先选择允许的跳跃反应，成功减同一次伤害，不产生第二次伤害 |
| 点火前宣布立即撤离且DEX成功 | 不进入毒气轮次；DEX失败才进入第一轮暴露 |
| 只有屏息，没有立即撤离 | 首轮免CON，第二轮仍暴露时做一次CON；每轮最多一次伤害 |
| 路线被实际妖鬼堵住 | 不能按正常两轮直接离开，继续逐轮结算暴露 |
| 两只妖鬼都无法响应 | 铜锣无援军；不生成第三只、不重复派遣同一个体 |
| MP0、HP2、SAN1触门 | 付1HP与1SAN，移动完成，再处理SAN0后果 |
| MP0、HP1，或SAN0触门 | 验证失败，不扣资源、不移动；本门的项目裁定避免透支与无代价传送 |

上表是待实现的验收约定，不宣称已运行对应事件代码。目前执行的检查是内容引用、选择值、图可达性与门禁结构。
