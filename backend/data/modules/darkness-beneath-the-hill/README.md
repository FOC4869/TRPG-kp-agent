# 岭下暗影：模组内容包

这是依据用户提供的完整中文粘贴正文与七张书内图片整理的 **内容包草案**。可离线阅读、审阅和建立索引；尚未接入 KeeperService、CLI 或 HTTP，不能传给现有 `--campaign` JSON 加载器。全部事件为声明记录，不执行 YAML 文本中的条件、骰子或效果。

## 文件与依据

- `manifest.yaml`：版本、文件索引、来源摘要与运行状态。
- `story.md`：完整来源正文，只插入 HTML 锚点，保留原始译注、页码和排版残留；章节是故事依据。
- `characters.yaml`：人物、平均生物模板及两只妖鬼实例；本局伤势与位置另存。
- `locations.yaml`：地点、地图编号、已选定的粗粒度场景图与高差/危险/笼门/传送条件。
- `clues.yaml`：发现途径、玩家事实与守秘人解释。
- `objects.yaml`：装置、铜锣、茧、铁笼、传送门等唯一实体。
- `events.yaml`：原文事件提取；成功、失败、延迟与例外说明；不是完整执行DSL。
- `endings.yaml`：多维结果与奖励；歧义表达式采用显式项目裁定。
- `keeper-options.yaml`：原文明示可选的主持安排，默认关闭。
- `issues.yaml`：原始疑点、处理方式、依据和限制措施。
- `assets/index.yaml`：七张原图、两份正文展示材料和24项已验收生成素材的统一索引。

所有 YAML 使用 UTF-8、`0.1.0` 草案约定；没有在本轮建立通用模组 schema。`source.document` 相对本模组根目录，`source.anchor` 指向正文 HTML id；`assets/index.yaml` 中 `file` 相对 assets/。实体关联使用稳定ID，素材标签可扩展，目录名不承担媒体类型或权限语义。

## 存储与检索契约

1. 以 manifest 的文件索引加载已声明资料；按稳定ID精确查找，再按关联实体和标签查找。七张图无需向量检索。
2. Keeper可读取完整正文与秘密地图；每轮选择上下文不影响原文完整存储。事件表未收录的行动仍允许按正文提出裁定。
3. 玩家只获取已揭示材料；先按 game_id、接收者和观察事实筛选候选，再进行玩家搜索，连标题、摘要和缩略图也要过滤。
4. `access.default: keeper_only` 为默认拒绝；非空 `player_reveal_fact` 是未来授权所需条件，当前没有实现授权接口。地图原图不直接给玩家，脱敏探索图另作派生素材。
5. 文字展示材料通过 `content_ref` 读取对应锚点至下一个章节锚点；不复制维护第二份信件/遗书。
6. 图片只辅助展示，不决定人数、物件数量、已发生动作或触发规则。看图/搜索不产生检定或扣血。
7. 每局状态、选用主持建议、已揭示事实、计时器、骰子、奖励记录放独立存档；绑定内容版本和内容指纹，绝不改写模组。
8. 正文与配置冲突须回到出处核对并修订版本；运行时不得让模型临时选择一套解释。

## 审阅状态

图片按原始字节保存并记录SHA-256。两张建筑身份待图注确认。地图2含地图3巢穴区域，二者共享实体；6是遗书标记、7是危险区域、多处5号为巢窟实例，不将每个编号都当新房间。0.2.0 对照地图建立粗粒度场景连通图；无编号通路合并为岔路节点，峭壁作为深入区域门禁属于显式项目抽象，不声称精确重建每条细支路。高差、陷坑、笼门与传送必须另处理，不能只按 bidirectional 自动行走。隐藏怪物窄道不作为调查员路线，追逐仍未适配。

16项来源疑点的采用值、项目裁定和限制措施见 rulings.yaml；issues保留原问题及解决方式。法术须从确认版本的规则书取得定义，不以RAG片段或模型常识替代规则实现。内容审阅完成也不代表这些运行能力已经具备。

本包包含用户提供的出版物资料，不声明原创或授予再分发许可；保留图片中原有署名。服务端存储不等于允许公开静态发布。


## 0.2.0 项目裁定

新增 `rulings.yaml`（清单入口 `files.rulings`），全部16项已有明确项目处理方案。`resolved` 只表示来源核实、项目选择或风险限制已记录；不表示官方勘误或游戏执行器已实现。官方规则链接、核对日期和裁定分类随包保存；manifest.rules.profile_sha256把裁定文件变动纳入内容指纹，专用检查验证该摘要。原始正文和图片保持原字节。

- 采用 CoC7 标准基线；蛇人HP取11并保留印刷20；妖鬼SAN补为0/1D8。
- 潜行、重试、SAN重复、爆炸、峭壁、毒气、召援和资源不足传送有确定的本项目约定，仍是 descriptive_only。
- 无图注建筑照片仅保留参考，禁止自动按具体建筑展示。原文本附件未恢复，派生正文不冒充原附件。
- 运行能力独立记录于 manifest.capabilities；法术定义、游戏适配和单人游玩测试仍需后续实现。
- `assets/adjudication-history-v1.json` 保存变更前内容、素材制作计划及索引。规则/粗粒度路线变化经复核不改变已验收图片；旧输入指纹保留，当前记录注明复核依据。

只读内容检查（不执行游戏）：

```sh
uv run --locked --script backend/data/modules/darkness-beneath-the-hill/checks/validate_rulings.py
uv run --locked --script skills/coc-module-builder/scripts/validate_module.py backend/data/modules/darkness-beneath-the-hill --complete
```

第一条检查裁定覆盖、采用值、事件引用、关键路线可达及门禁；不冒充毒气、战斗或传送执行器测试。第二条校验内容和素材格式、出处、哈希与验收指纹。
