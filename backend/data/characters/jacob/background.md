# 雅各布·吉普森

<a id="appearance"></a>
## 个人描述

就中国人而言，他只比常人略高，身形削瘦，黑色头发。多年的体力劳动使他非常健壮，虽然算不上身手矫健。他的双手粗糙，布满老茧和各种小伤口。

<a id="traits"></a>
## 特质

天生很安静，态度谦逊。他很鄙视那些自认为高他一等的自大白人家伙。

<a id="beliefs"></a>
## 思想与信念

<a id="history"></a>
## 人物经历

雅各布在一所大学干门卫和勤杂工。他懂很多关于维修和养护的知识，有这方面的一些技术经验。雅各布在情形紧张时往往能保持冷静。他经常被朋友和同事请求做一些“私下的”工作，甚至包括盗窃和非法入侵。许多教授和学生都因为一些棘手的事情欠他人情。
