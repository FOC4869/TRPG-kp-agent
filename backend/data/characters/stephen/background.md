# 史蒂芬·谢泼洛夫斯基神父

<a id="appearance"></a>
## 个人描述

身材瘦高，面容年轻却有些憔悴，在教堂工作的时候穿着他的黑色制服和教士领。他的棕色短发和大大的深棕色眼眸很般配。

<a id="traits"></a>
## 特质

温和的性格下隐藏着敏锐的思维和强烈的使命感。话很少，观察力敏锐，不好跟别人抢风头。在基本的人性之上有着一颗深深地为他人着想的心。

<a id="beliefs"></a>
## 思想与信念

坚定的天主教信徒。

<a id="history"></a>
## 人物经历

作为一个新人神父，谢泼洛夫斯基神父有着援助被困扰的灵魂的使命感，这份与生俱来的同情心有事会让这名年轻的神父陷入他力所不能及的境地，然而到目前为止，仁慈的上帝总会给他一个补救的机会。谢泼洛夫斯基得到了教区里的老神父的支持，老神父很欣赏他能为了不幸的人们自愿出力，虽然谢泼洛夫斯基的善心有时会引领他来到一些怪异的地方。因此，老神父给了谢泼洛夫斯基足够的自由，让他能够从每日的教堂事务中脱身去外面帮助那些需要帮助的人。

## 原卡译注

原卡特质栏另有英文：beyond the initial reserve dwells a warm personality that cares deeply for others；并附译注“能力有限这句实在不大会翻，姑且意译一下”。上方保留原卡已有中文。
