# 大卫“不可思议的克雷格”威尔考克斯

<a id="appearance"></a>
## 个人描述

他比一般人矮一些，瘦削且敏捷灵活。黑头发、亮蓝色的眸子，有着从无数的现场演出中磨练出来的魅力。

<a id="traits"></a>
## 特质

有点爱卖弄炫耀（随时都能准备着表演他的扑克魔术），友善外向。

<a id="beliefs"></a>
## 思想与信念

不要被别人欺骗，对所有的事保持怀疑。

<a id="history"></a>
## 人物经历

大多数舞台魔术师都是愤世嫉俗的人——世上最知名的怀疑论者有些就当过魔术师。大卫是个例外。他接触“魔法”是因为他心底深信现实中一定有很多不为大多数人所知晓的东西。尽管他已经追寻了“真正的魔法”许多年，大卫从未遇到任何跟魔法沾上一点边的事物，除了他的表演。大卫坚持寻找着不可思议的事件、奇怪的谜团，和那些声称自己有魔法天赋的人们，只为了有一天能看到常人所不能见到的东西。
